# Apeyron Lab

We are the product lab of [Apeyron](https://apeyron.it), based in Italy. This is where we publish and develop our open-source software.

We care about useful products, understandable code, clear documentation, and learning from the people who use what we build.

## First project: Theatron

[Theatron](https://theatronmc.com) helps Minecraft creators build interactive worlds with dialogue, quests, and visual rules. We are preparing an open-source release so communities can run it themselves and contribute. The repository and self-hosting instructions will appear here when they are ready.

## Get in touch

For questions about Apeyron Lab, write to [info@apeyron.it](mailto:info@apeyron.it). Project-specific issues and contribution guidelines will live in each repository.
